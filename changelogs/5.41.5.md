# 5.41.5
Released 6th April 2026.

This release fixes powder snow bucket placement targeting on existing powder snow blocks.
This release completes Copper Golem Statue integration and fixes registry/mapping inconsistencies.

## Fixed
- Fixed powder snow bucket behavior when clicking existing powder snow blocks. The bucket now places into the adjacent target block (for example, the block above when clicking the top face) instead of rewriting the clicked powder snow block.
- Preserved replace-in-place behavior for thin replaceable targets like snow layer and leaf litter.
- Fixed Copper Golem Statue block registrations to use the correct tile class binding, preventing tile validation/runtime registration failures.
- Added missing Copper Golem Statue variant registrations to the input registry so generated/runtime block registries remain aligned.
- Added missing Copper Golem Statue type ID constants and updated the first-unused runtime block ID.
- Added missing Bedrock flattened ID mapping for Copper Golem Statue (including wax/oxidation variants and horizontal facing).
- Restored copper tool interactions on Copper Golem Statue (honeycomb waxing and axe scrape/unwax) while preserving pose-cycling interaction.
